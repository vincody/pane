# A workspace that stays out of your way.

Welcome to **AI Web** — a small local editor for the projects your agents work on.

## Start with a file

1. Expand a folder in the sidebar.
2. Open a code file and make an edit.
3. Press **Ctrl+S** to save it to disk.
4. Select **Split** to see a preview alongside the editor.

> Your changes stay local. If an agent modifies a file while you are editing it, AI Web asks you to reload instead of overwriting that change.

## Built for everyday work

| Files | Preview |
| --- | --- |
| Markdown | Rendered text, lists, tables, code |
| Images | PNG, JPEG, WebP, GIF, SVG |
| HTML | Static, isolated preview |
| Code | Syntax-highlighted source |

```javascript
const workspace = {
  local: true,
  editor: 'Monaco',
  ready: true,
};
```

Use **Open folder** to switch to your own project.
